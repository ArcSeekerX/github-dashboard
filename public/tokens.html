GitHub API 不提供「列出账号全部 PAT」的接口（官方仅网页端可见），因此请把需要管理的 Token 在这里登记一次：新增时自动校验，之后可集中查看完整信息、一键复制/显示、设为活跃。
Token 保存在本地 config.json（已 gitignore）。「刷新状态」会逐个调用 api.github.com 读取账号、scopes、有效期与速率配额；「设为活跃」会让看板与 agent 改用该 Token（写入 github.token）。
